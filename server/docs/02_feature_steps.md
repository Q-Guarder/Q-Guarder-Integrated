# 02_feature_steps.md

| 단계 (Step) | 목적 (Purpose) | 세부 개발 과정 (Processes) | 완성되는 파일들 (Target Files) |
| :--- | :--- | :--- | :--- |
| **Step 1<br>초기 환경 세팅** | 프로젝트의 뼈대를 잡고 필요한 라이브러리 설치 | 1. 파이썬 가상환경 생성<br>2. FastAPI, SQLAlchemy 등 필수 패키지 목록 작성<br>3. 깃허브에 올리면 안 되는 파일(보안키 등) 제외 설정 | `requirements.txt`<br>`.gitignore` |
| **Step 2<br>코어 및 DB 연결** | 앱의 전반적인 환경 변수 로드 및 DB, 보안(암호화) 기초 공사 | 1. DB 주소, JWT 시크릿 키 등을 불러오는 환경설정 파일 세팅<br>2. 비밀번호 암호화 및 JWT 토큰 발급 로직 작성<br>3. DB와 통신할 수 있는 세션(Session) 연결 고리 생성 | `app/core/config.py`<br>`app/core/security.py`<br>`app/db/session.py` |
| **Step 3<br>데이터베이스 모델링** | 설계한 ERD를 파이썬 코드(SQLAlchemy)로 번역하여 DB 테이블화 | 1. USERS 테이블 생성<br>2. SCAN_LOGS, SCORE_DETAILS 생성<br>3. VISIT_HISTORY, BOOKMARKS 생성<br>4. REPORTED_URLS, FEEDBACK_QUEUE 생성<br>5. ML_MODELS 테이블 생성 | `app/models/user.py`<br>`app/models/scan.py`<br>`app/models/log.py`<br>`app/models/report.py`<br>`app/models/ml_model.py` |
| **Step 4<br>데이터 검증 (Schema)** | API로 들어오고 나가는 데이터의 형태(JSON)를 정의하고 오류 필터링 | 1. 회원가입/로그인 입출력 양식 정의 (Pydantic)<br>2. 스캔 요청/응답 양식 정의<br>3. 신고하기 접수 폼 정의<br>4. 로그/즐겨찾기 리스트 출력 양식 정의 | `app/schemas/auth_schema.py`<br>`app/schemas/scan_schema.py`<br>`app/schemas/report_schema.py`<br>`app/schemas/user_log_schema.py` |
| **Step 5<br>DB 조작 (CRUD)** | DB에 데이터를 넣고(Create), 읽고(Read), 수정(Update), 삭제(Delete)하는 함수 작성 | 1. 회원 가입 및 유저 조회 함수<br>2. 스캔 기록 및 점수 저장 함수<br>3. 신고 데이터 큐(Queue) 적재 함수<br>4. 즐겨찾기 및 접속 기록 저장/조회 함수 | `app/crud/crud_user.py`<br>`app/crud/crud_scan.py`<br>`app/crud/crud_report.py`<br>`app/crud/crud_log.py` |
| **Step 6<br>핵심 비즈니스 로직** | 단순 DB 저장을 넘어, 외부 API 연동 및 알고리즘 처리를 전담하는 서비스 구현 | 1. local_models/의 모델(model.pkl)을 메모리에 로드<br>2. LightGBM + VirusTotal 검사 융합 로직 작성<br>3. 위험 URL 신고 시 SMTP(Gmail 등)로 KISA에 메일을 보내는 로직 작성 | `app/services/model_loader.py`<br>`app/services/hybrid_engine.py`<br>`app/services/kisa_reporter.py` |
| **Step 7<br>API 라우터 연결** | API 명세서의 주소(Endpoint)들을 실제 함수(CRUD, Service)와 연결하여 통신구 개방 | 1. `/api/v1/auth/*` 라우터 작성<br>2. `/api/v1/scan/*` 라우터 작성<br>3. `/api/v1/report` 라우터 작성<br>4. `/api/v1/users/me/*` 라우터 작성 | `app/api/v1/auth.py`<br>`app/api/v1/scan.py`<br>`app/api/v1/report.py`<br>`app/api/v1/user_logs.py` |
| **Step 8<br>앱 통합 및 백그라운드** | 흩어진 모든 라우터를 하나의 앱으로 조립하고 비동기 작업 스크립트 완성 | 1. FastAPI 객체 생성 및 라우터 등록<br>2. 큐를 읽어 VT 재검사를 실행하는 백그라운드 스크립트 작성 (필요할 때 직접 실행) | `app/main.py`<br>`background/queue_processor.py` |
